CORE FLOW

从求职信息到下一步行动

01

动态岗位搜索

Profile 与 Preferences 生成本次 Search Intent，在真实公开来源中筛选、去重和排序。

02

匹配与差距分析

本机 Ollama 输出结构化匹配分析，清晰展示优势、潜在不足和可执行建议。

03

申请辅助，而非代替

Chrome Companion 识别字段、匹配资料并提供可复制建议；所有填写和提交仍由用户决定。
