# 职跃 AI · 申请助手（本机 Demo）

1. 在职跃 AI 的“我的档案”保存资料，复制显示的本机访问密钥。
2. 在 Chrome 打开 `chrome://extensions`，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择仓库中的 `browser_extension/` 目录。
4. 打开 Greenhouse、Lever、Ashby 或官方申请页，点击扩展图标，粘贴访问密钥后点击“识别申请表”。

扩展仅在用户点击后读取当前页的公开表单字段及标签，不读取密码、支付信息或整页内容；它只提供复制建议，不会自动填写、上传、跳转、点击 Next 或 Submit。
